Flagship

Helpdesk AI

Live demo GitHub

A multi-tenant SaaS where a business uploads PDFs, DOCX files and FAQs and gets a customer-facing chat agent. It answers only from that knowledge, cites its sources, says "I don't know" instead of inventing policy, and hands hard conversations to a human through a ticket system.

  • LangGraph agent with intent routing, retrieval, a relevance threshold and automatic escalation after repeated misses.
  • Tenant isolation on every query, argon2 passwords, HTTP-only JWT cookies, owner and agent roles.
  • Prompt-injection guardrails, rate limits, per-organization daily quotas and a RAG evaluation script.
  • Owner dashboard with conversations, tickets and analytics.

Document Q&A

FileWhisperer

Live demo GitHub Case study

Upload your files, ask questions in plain language and get answers grounded in those documents, with a Sources panel under every reply. It pairs a lightweight TF-IDF retriever with an LLM, so it works without a vector database.

  • Reads TXT, MD, CSV, JSON, PDF, DOCX and XLSX, and runs OCR on scanned PDF pages in parallel.
  • Detects two-column PDF layouts so text reads in the right order.
  • User accounts with PBKDF2 hashing, saved chat history and an invite code for public deployments.

Zorvi AI Studio

Live demo GitHub

A marketing studio for small businesses. Upload a product photo, get captions, hashtags and promo copy, design an editable social graphic and export it as PNG, JPG or a full marketing-kit ZIP.

  • Sign-up with email verification and password reset, scrypt-hashed passwords and a login lockout.
